# Task Brief Template

Use this template to start focused AI-assisted work.

```text
Task:
<Describe the requested change or investigation.>

Scope:
<List packages, docs, or commands that are in scope.>

Out of scope:
<List related work that should not be touched.>

Expected behavior:
<Describe the observable behavior after the change.>

Validation:
<List tests, harness commands, or manual checks expected.>

Notes:
<Add context, constraints, or relevant issue links.>
```

## Completion Checklist

- Relevant code was read before editing.
- Changes are scoped to the task.
- Public behavior is documented.
- Tests or validation commands were run.
- Known limitations are reported.
